# General Agent

Minimalny handbook techniczny dla wykonawców (Cursor / Codex) w repozytorium `kwaczur/general-agent`.

## Notion ↔ GitHub

- **Notion** — źródło prawdy dla scope’u, approval, dry runu, decyzji operatora i raportu Zlecenia builderskiego.
- **GitHub** — źródło prawdy dla kodu, plików, branchy, commitów, Pull Requestów, testów i stanu technicznego.

Szczegóły: [AGENTS.md](./AGENTS.md).

## Handbook

| Plik | Opis |
|------|------|
| [AGENTS.md](./AGENTS.md) | Zasady technicznego wykonania |
| [docs/builder-workflow.md](./docs/builder-workflow.md) | Cykl: Zlecenie → dry run → approval → branch → testy → PR → raport |
| [docs/report-template.md](./docs/report-template.md) | Szablon dowodów i raportu |

Każda praca repozytoryjna wymaga **ID Zlecenia** w branchu (gdy możliwe), w tytule PR oraz w raporcie Notion.
